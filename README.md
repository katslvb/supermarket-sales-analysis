# supermarket-sales-analysis
Анализ продаж супермаркета в Excel: дашборд, сводные таблицы, выводы
## О проекте
**Цель:** Провести анализ продаж сети супермаркетов за 2019 год, выявить ключевые точки роста и дать бизнес-рекомендации.

**Инструменты:** Microsoft Excel (очистка данных, сводные таблицы, дашборд).

## Ключевые результаты
- **Гендерный анализ:** Мужчины и женщины приносят равную выручку (разница 0.5%), но предпочитают разные категории.
- **Товарная прибыльность:** Категория `Food and beverages` имеет высокую выручку, но и самую высокую себестоимость.
- **Региональный анализ:** Город Mandalay требует проверки ценообразования (выручка в 7 раз ниже при том же объеме продаж).
- **Временной анализ:** Пик продаж — январь и февраль. Часы пиковой нагрузки на кассы — 13:00–14:00 и 18:00–19:00.

## Как посмотреть проект
1. Скачайте файл `Анализ_продаж_супермаркета_дашборд.xlsx`
2. Откройте лист `Dashboard` для интерактивной версии
3. Или посмотрите PDF-версию
